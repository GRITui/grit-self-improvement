# Wireframes — TSK-004

Low-fidelity, layout-only wireframes (ASCII box diagrams) for the three MVP screens named in
`PROJECT_BRIEF.md` §5 items 1, 4, and 6. These define **structure and content hierarchy**, not
final visuals — see `../tokens.md` for color/type/spacing to apply during implementation.
Placeholder styling is fine per TSK-004's description; do not block on TSK-003 details.

| File | Screen | MVP scope ref |
|---|---|---|
| `landing-page.md` | Marketing landing page | §5 item 8 |
| `coach-dashboard.md` | Coach dashboard (client list + drill-in) | §5 item 6 |
| `client-checkin.md` | Public client check-in page | §5 item 4 |

## Conventions used in these diagrams

- `[Button Label]` — primary/secondary button
- `{Badge}` — status/risk badge (pill)
- `<Input field>` — form input
- Boxes are desktop-width by default; a "Mobile" variant follows where layout reflows
  significantly rather than just stacking.
